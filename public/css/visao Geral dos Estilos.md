# Estrutura da pasta css

- `base/`: estilos partilhados do projecto.
- `home/`: estilos da pagina inicial.
- `institucional/`: estilos das paginas `sobre` e `contacto`.
- `admin/`: estilos da area administrativa.
- `cadastro/`: estilos das paginas de cadastro.
- `cliente/`: estilos das paginas do cliente.
- `login/`: estilos das paginas de login.
- `prestador/`: estilos das paginas do prestador.
- `servicos/`: estilos das paginas de explorar e detalhe de servicos.
