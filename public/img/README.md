# Estrutura da pasta img

- `home/hero/`: imagens exclusivas da pagina inicial.
- `servicos/categorias/`: icones e imagens usadas nas paginas de servicos e categorias.
- `shared/avatares/`: avatar padrao reutilizado em cards e listagens.
- `shared/usuarios/`: fotos de utilizadores usadas em perfis, dashboards e navegacao.
- `arquivos-originais/`: ficheiros antigos ou de apoio que nao estao ligados directamente as paginas actuais.

## Regra de organizacao

- Imagens especificas de uma area devem ficar dentro da pasta dessa area.
- Imagens reutilizadas entre varias paginas devem ficar em `shared/`.
- Ao adicionar uma nova imagem, actualizar sempre o caminho nas paginas HTML ou CSS correspondentes.
