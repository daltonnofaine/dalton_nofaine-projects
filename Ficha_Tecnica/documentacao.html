estilo.css

CSS Global
Ficheiro de estilos partilhado por todas as paginas. Contem o reset, as variaveis de cor, a navegacao, os botoes, o rodape e os campos de formulario.
Tipo
CSS Partilhado
Usado em
Todas as paginas
Blocos
6 blocos
Bloco 1 — Reset Basico 1
Remove o espaco padrao que os browsers colocam automaticamente em todos os elementos. Garante que a pagina apareca igual em todos os browsers.
* { margin: 0; padding: 0; } O asterisco (*) selecciona TODOS os elementos da pagina. Remove o espaco exterior (margin) e o espaco interior (padding) de tudo.
box-sizing: border-box; Faz com que o tamanho de um elemento inclua a sua borda e padding. Facilita o calculo de larguras.
Bloco 2 — Variaveis de Cor 2
Define as cores principais do projecto num unico lugar. Ao mudar o valor aqui, a cor actualiza em toda a pagina automaticamente.
:root { } Selecciona o elemento raiz do documento (o HTML). E onde se declaram as variaveis CSS.
--preto: #1A1A2E; Cria a variavel chamada "preto" com um azul-escuro. Para usar: var(--preto)
--vermelho: #E84855; Cor de destaque usada em botoes, etiquetas e elementos principais.
--cinza: #9B9B9B; Cinza medio para textos secundarios, como descricoes e legendas.
--borda: #C8C4BC; Cor usada nas bordas dos elementos, como linhas e contornos de campos.
--fundo: #F5F3EE; Cor de fundo suave usada em seccoes alternadas e campos de formulario.
--branco: #FFFFFF; Branco puro para fundos de cards e areas principais.
Bloco 3 — Corpo da Pagina 3
Define o aspecto visual base de todo o texto e fundo da pagina.
font-family: Arial, sans-serif; Define a fonte principal. Arial e a primeira opcao; se nao existir no dispositivo, usa qualquer fonte sem serifa.
font-size: 14px; Tamanho base do texto em toda a pagina. Os outros tamanhos sao definidos em relacao a este.
color: #1A1A2E; Cor padrao do texto (azul muito escuro, quase preto).
background: #FFFFFF; Fundo branco para toda a pagina.
Bloco 4 — Navegacao (nav) 4
Estilos da barra de navegacao no topo. Aparece em todas as paginas do site.
border-bottom: 2px solid var(--preto); Linha de separacao por baixo da nav com 2 pixeis de espessura, usando a variavel --preto.
padding: 0 40px; Espaco interior horizontal de 40 pixeis (esquerda e direita). Vertical fica a zero.
height: 60px; Altura fixa da barra de navegacao: 60 pixeis.
display: flex; Activa o sistema Flexbox, que permite alinhar os filhos em linha.
align-items: center; Alinha os elementos filhos ao centro verticalmente dentro dos 60px de altura.
justify-content: space-between; Coloca o logo do lado esquerdo e os links do lado direito, com espaco maximo entre eles.
Bloco 5 — Botoes 5
Tres tipos de botao reutilizaveis em todo o site: contorno, preenchido e vermelho.
.btn Botao com contorno (borda preta, fundo transparente). Usado para accoes secundarias.
.btn-preenchido Botao preenchido a preto com texto branco. Usado para accoes principais.
.btn-vermelho Botao vermelho. Usado para accoes de destaque maximo (ex: "Enviar Pedido").
cursor: pointer; Muda o cursor do rato para uma mao quando passa por cima, indicando que e clicavel.
display: inline-block; Permite que a tag <a> se comporte como botao, aceitando padding e dimensoes.
Bloco 6 — Rodape e Campos de Formulario 6
Estilos do rodape escuro no fundo de cada pagina, e dos campos de texto/select/textarea usados nos formularios.
footer { background: var(--preto); } Fundo escuro para o rodape, usando a variavel de cor.
.footer-grid { display: grid; grid-template-columns: 2fr 1fr 1fr 1fr; } Divide o rodape em 4 colunas: a primeira tem o dobro da largura das restantes.
.campo label { text-transform: uppercase; } Converte o texto do label para maiusculas automaticamente via CSS.
border: 2px solid var(--borda); Borda cinza nos campos de formulario. Fica preta quando o campo esta activo (focus).
outline: none; Remove o contorno azul que os browsers colocam por padrao nos campos activos.
resize: vertical; Permite ao utilizador redimensionar o textarea apenas na vertical.

Blocos HTML
4 blocos
Bloco 1 — Cabecalho do documento (<head>) 1
A tag <head> nao e visivel no ecra. Contem informacoes sobre a pagina e os links para os ficheiros CSS.
<meta charset="UTF-8"> Define a codificacao de caracteres. Necessario para mostrar acentos e caracteres especiais correctamente.
<meta name="viewport"...> Torna a pagina responsiva em telemoveis. Sem isto, a pagina aparece muito pequena em ecras pequenos.
<title>ServeNow - Home</title> Texto que aparece no separador do browser.
<link rel="stylesheet" href="estilo.css"> Liga o ficheiro CSS global. O rel="stylesheet" diz ao browser que e um ficheiro de estilos.
<link rel="stylesheet" href="index.css"> Liga o CSS especifico desta pagina. Carregado a seguir ao estilo.css.
Bloco 2 — Navegacao (<nav>) 2
Barra de navegacao no topo. Contem o logo e os links principais incluindo os botoes de entrada e registo.
<nav> Tag semantica HTML para navegacao. O browser e os motores de busca sabem que este bloco e um menu.
<div class="logo"> Contentor do nome da marca. O estilo .logo esta definido no estilo.css.
<span>Serve</span>Now O <span> envolve "Serve" para lhe dar a cor vermelha via CSS, sem afectar "Now".
class="btn" Aplica o estilo de botao com contorno (definido no estilo.css) ao link "Entrar".
class="btn-preenchido" Aplica o estilo de botao preenchido a preto ao link "Cadastrar".
href="cadastro.html" Ao clicar, navega para a pagina de cadastro.
Bloco 3 — Hero (<section class="hero">) 3
A seccao de destaque no topo da pagina. Contem o titulo, descricao, barra de pesquisa e os numeros estatisticos.
<section class="hero"> Tag semantica para uma seccao da pagina. A classe "hero" aplica o fundo escuro e o padding definidos no index.css.
<h1> Titulo principal da pagina. Deve haver so um <h1> por pagina — e o titulo mais importante.
<span>certo</span> Envolve a palavra "certo" para lhe aplicar a cor vermelha via CSS.
class="barra-pesquisa" Contentor da barra de pesquisa. O CSS no index.css usa flex para alinhar o input e o botao lado a lado.
<input type="text"> Campo de texto onde o utilizador escreve o servico que procura.
class="numeros" Contentor das tres estatisticas (prestadores, servicos, satisfacao). Usa flex para os mostrar em linha.
Bloco 4 — Como Funciona e Prestadores 4
Duas seccoes: os 4 passos de utilizacao da plataforma e os cards dos prestadores verificados. Seguidas do rodape.
<section class="como-funciona"> Seccao com fundo cinza (var(--fundo)) que explica o processo de utilizacao em 4 passos.
class="passos" Grelha com 4 colunas iguais (definido no index.css com grid-template-columns: repeat(4, 1fr)).
class="passo" Card individual de cada passo, com borda e fundo branco.
class="numero-passo" Texto "Passo 01", "Passo 02", etc. Estilizado em vermelho e letras pequenas com espacamento.
class="prestadores-verificados" Seccao com fundo branco que mostra 4 prestadores em grelha.
class="lista-prestadores" Grelha de 4 colunas para os cards dos prestadores.
class="card-prestador" Card individual do prestador com avatar, nome, especialidade e etiqueta "Verificado".
class="avatar" Circulo cinza que representa a foto do prestador (placeholder).
<footer> Rodape escuro com 4 colunas de links. Estilo definido no estilo.css.

color: rgba(255,255,255,0.65); Branco com 65% de opacidade, criando um cinza claro para o paragrafo de descricao.

Input e botao de pesquisa alinhados lado a lado dentro do hero.
.barra-pesquisa { display: flex; } Flex coloca o input e o botao lado a lado automaticamente.
max-width: 500px; Limita o comprimento maximo da barra.

.barra-pesquisa input { flex: 1; } O input expande para ocupar todo o espaco disponivel, deixando o botao com o seu tamanho natural.

Grelhas de 4 colunas para os passos e os cards dos prestadores.
.passos { display: grid; grid-template-columns: repeat(4, 1fr); } Cria uma grelha com 4 colunas de largura igual. "repeat(4, 1fr)" e o mesmo que escrever "1fr 1fr 1fr 1fr".

.passo { border: 2px solid var(--borda); } Borda cinza em cada card de passo.
text-align: center; Centra todo o conteudo dentro do card (numero, titulo, descricao).

Blocos HTML
5 blocos
Bloco 1 — Bloco Esquerdo (Beneficios) 1
Painel lateral escuro com titulo e lista de beneficios da plataforma. Ocupa 340px de largura fixa.
class="bloco-esquerdo" Painel escuro da esquerda. Tem width: 340px fixo e flex-shrink: 0 para nao encolher.

Bloco 2 — Selector de Tipo de Conta 2
Dois botoes selectores: Cliente e Prestador. O clique activa o JavaScript que mostra ou esconde os campos adicionais.
class="tipo-conta" Grelha de 2 colunas iguais para os dois selectores ficarem lado a lado.
class="opcao-tipo activo" A classe "activo" e adicionada pelo JavaScript ao selector escolhido, mudando a sua aparencia (borda preta, fundo cinza).
id="btn-cliente" Identificador unico usado pelo JavaScript para encontrar este elemento e manipula-lo.
onclick="escolherTipo('cliente')" Ao clicar, chama a funcao JavaScript "escolherTipo" passando o valor "cliente".
Bloco 3 — Campos Basicos do Formulario 3
Campos comuns a todos os utilizadores: nome, apelido, email, telefone e senha. Aparecem sempre.
class="dois-campos" Grelha de 2 colunas para colocar campos lado a lado (ex: Nome e Apelido).
class="campo" Contentor de cada campo com label + input. O estilo esta no estilo.css.
type="email" Campo de email. O browser valida automaticamente que o texto tem formato de email.
type="password" Campo de senha. O texto digitado aparece como pontos para seguranca.
Bloco 4 — Campos do Prestador (ocultos) 4
Bloco com campos extras apenas para Prestadores. Começa oculto (display: none) e aparece ao clicar em "Prestador".
class="campos-prestador" Por defeito tem display: none no CSS, tornando-o invisivel.
id="campos-prestador" ID usado pelo JavaScript para encontrar este bloco e adicionar a classe "visivel".
class="campos-prestador visivel" Quando o JavaScript adiciona a classe "visivel", o CSS muda para display: block, tornando o bloco visivel.
Bloco 5 — JavaScript (logica do selector) 5
Codigo JavaScript que controla qual tipo de conta esta seleccionado e mostra/esconde os campos do prestador.
function escolherTipo(tipo) { } Funcao chamada quando o utilizador clica num dos selectores. Recebe "cliente" ou "prestador".
document.getElementById('btn-cliente') Encontra o elemento HTML com id="btn-cliente" para o poder modificar.
classList.add('activo') Adiciona a classe CSS "activo" ao elemento, mudando a sua aparencia visual.
classList.remove('activo') Remove a classe CSS "activo" do outro elemento, voltando ao estilo normal.
camposPrestador.classList.add('visivel') Adiciona a classe "visivel" ao bloco de campos do prestador, tornando-o visivel via CSS.
camposPrestador.classList.remove('visivel') Remove a classe "visivel", voltando a esconder o bloco de campos do prestador.
O JavaScript nao cria nem apaga elementos — apenas adiciona e remove classes CSS. E o CSS que decide se o bloco e visivel ou nao, atraves de display: none e display: block.

CSS
Estilos do layout de dois blocos, dos selectores de tipo de conta e dos campos condicionais do prestador.
Bloco 1 — Layout de Dois Blocos 1
.pagina-cadastro { display: flex; } Flex coloca o bloco esquerdo e o formulario lado a lado na horizontal.
min-height: calc(100vh - 60px); Altura minima igual ao ecra inteiro menos os 60px da navegacao. Garante que a pagina preenche o ecra.

.opcao-tipo.activo { border-color: var(--preto); background: var(--fundo); } Quando activo: borda escura e fundo cinza claro. O ponto (.) une as duas classes — so aplica quando o elemento tem AMBAS as classes.
.campos-prestador { display: none; } Esconde o bloco por defeito. Sera substituido por display: block quando a classe "visivel" for adicionada.
.campos-prestador.visivel { display: block; } Mostra o bloco quando tem a classe "visivel". O JavaScript e que adiciona e remove essa classe.

class="painel" Card com borda que envolve cada seccao do dashboard (tabela, avaliacoes, servicos).
class="area-grafico" Rectangulo com borda tracejada que representa o espaco para um futuro grafico.
<table> Elemento HTML de tabela com linhas (<tr>), cabecalhos (<th>) e celulas (<td>).
<thead> e <tbody> <thead> contem a linha de cabecalho. <tbody> contem as linhas de dados. Boa pratica para acessibilidade.
class="estado confirmado" Etiqueta de estado com cor verde. Existem tres variantes: confirmado (verde), pendente (amarelo), concluido (azul).
Bloco 5 — Dois Paineis (Avaliacoes e Servicos) 5
class="dois-paineis" Grelha de 2 colunas iguais (1fr 1fr) para mostrar avaliacoes e servicos lado a lado.
class="avaliacao-item" Cada avaliacao com nome, estrelas e texto da avaliacao. Separados por border-bottom.
class="lista-meus-servicos" Lista dos servicos do prestador com nome e etiqueta de estado (activo/pausado).
class="linha-servico" Linha cinza com o nome do servico a esquerda e a etiqueta de estado a direita, usando justify-content: space-between.

CSS
Estilos do layout com sidebar, dos cards de metricas, da tabela de pedidos e dos paineis de conteudo.
Bloco 1 — Layout e Sidebar 1
.layout-dashboard { display: grid; grid-template-columns: 210px 1fr; } Sidebar fixa de 210px a esquerda, conteudo ocupa o resto a direita.
min-height: calc(100vh - 60px); A grelha tem pelo menos a altura do ecra menos a barra de nav, para a sidebar chegar ao fundo da pagina.
.item-menu.activo { border-left: 3px solid var(--vermelho); } Linha vermelha de 3px a esquerda do item activo. Indicador visual de localizacao no menu.
.badge-msg { margin-left: auto; } O "auto" no margin empurra o badge para a extremidade direita dentro do item flex.
Bloco 2 — Metricas, Tabela e Paineis 2
.grade-metricas { grid-template-columns: repeat(4, 1fr); } Quatro colunas de largura igual para os cards de metricas.
.conteudo-dashboard { background: var(--fundo); } Fundo cinza claro para a area de conteudo, criando contraste com os cards brancos.
table { border-collapse: collapse; } Remove os espacos entre as bordas das celulas da tabela, criando uma grelha continua.
th { background: var(--fundo); text-transform: uppercase; } Cabecalho da tabela com fundo cinza e texto em maiusculas para diferenciar dos dados.
td { border-top: 1px solid var(--borda); } Linha de separacao fina entre cada linha da tabela.
.estado.confirmado { background: #D4EDDA; color: #155724; } Estilo especifico da etiqueta "Confirmado": fundo verde claro e texto verde escuro.
.dois-paineis { grid-template-columns: 1fr 1fr; } Os dois paineis inferiores (Avaliacoes e Servicos) ficam lado a lado com largura igual.
